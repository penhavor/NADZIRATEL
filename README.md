# NADZIRATEL

**v1.0.0 (BUILD 120)** — процедурный хоррор от первого лица на чистом WebGPU:
без движка, зависимостей, сборки и ассетов — текстуры, модели, анимации, звуки
и музыка генерируются в рантайме из сида.

Вы заперты в тёмном лабиринте. Где-то далеко в одной из тумбочек лежит
маленький ключ, впереди — запертая дверь «ВЫХОД», а по коридорам патрулирует
Надзиратель: сутулая тень, которая слышит ваш бег, видит вас в узком конусе
зрения, а на высокой сложности телепортируется сквозь темноту к источнику шума.
Найдите ключ, возьмите фонарик в сейф-комнате и сбегите.

## Запуск

Откройте `index.html` в браузере с поддержкой **WebGPU** (актуальные версии
Chrome, Edge, Firefox, Safari). Локальный сервер не обязателен — обычные
скрипты работают и по `file://`. Если рендер сообщает, что WebGPU недоступен, —
включите аппаратное ускорение в настройках браузера.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | движение (обычный шаг бесшумен) |
| `Shift` | бег — шумит и тратит стамину |
| `C` | присесть/встать |
| `E` | взаимодействие (только когда прицел превратился в ладонь) |
| `F` | фонарик |
| `R` | заменить батарейку |
| `1`–`4` | слот инвентаря в руку |
| `G` | бросить предмет |
| `M` | миникарта |
| `Esc` | пауза |

Все бинды переназначаются в «Настройки → Управление и бинды» и сохраняются
между сессиями. Полные правила — в «Справочнике» внутри игры.

## Структура проекта

Проект собран из классических скриптов без бандлера, поэтому **порядок
загрузки файлов в `index.html` имеет значение**: сначала ядро с игровой
логикой, затем рендерер, затем звук/интерфейс и запускающий файл.

## Технические детали

- **Детерминизм.** Сид — любой текст (слово, фраза, эмодзи): через SHA3-512 он
  превращается в 512-битное состояние Xoshiro512**. У каждой подсистемы
  (лабиринт, лампы, монстр, текстуры, звук) свой параллельный поток (`jump()`),
  поэтому один и тот же сид даёт идентичный забег. Полный сид виден в паузе и
  копируется одним кликом.
- **Графика.** Рендер всегда через WebGPU; тяжёлые кадровые стадии (угловая
  карта теней, скиннинг, поле облучённости) выполняются в compute-шейдерах.
  Пресет графики меняет разрешение рендера/атласа и число сэмплов пост-эффектов,
  но не густоту темноты и не число источников света — переключение пресета не
  даёт игрового преимущества.
- **Масштаб мира.** 1 клетка ≈ 2.94 м, рост героя ровно 1.80 м. Скорости заданы
  в км/ч; походка Надзирателя выведена из походки игрока по равному числу
  Фруда (опорная нога не проскальзывает).
- **Режим разработчика** включается параметром URL `?dev=<пароль>` и нигде не
  сохраняется: в коде лежит только SHA3-512-дайджест пароля, а не пароль.
