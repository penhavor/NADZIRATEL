# NADZIRATEL

**v1.0.0 (BUILD 121)** — процедурный хоррор от первого лица на чистом WebGPU:
без движка, зависимостей и ассетов — текстуры, модели, анимации, звуки
и музыка генерируются в рантайме из сида.

Вы заперты в тёмном лабиринте. Где-то далеко в одной из тумбочек лежит ключ,
впереди — запертая дверь с надписью «ВЫХОД», а по коридорам патрулирует
Надзиратель: сутулое существо, которое слышит ваш бег, видит вас в узком конусе
зрения, а на высокой сложности телепортируется сквозь темноту к источнику шума.
Найдите ключ и сбегите, не попавшись монстру на глаза. Удачи!

## Структура проекта

Проект собран из классических скриптов без бандлера, поэтому **порядок
загрузки файлов в `index.html` имеет значение**: сначала ядро с игровой
логикой, затем рендерер, затем звук/интерфейс и запускающий файл.

## Тесты и сборка

- `node tests/run.js` — headless-тесты всей игры; `node tests/run.js -s 07_sim`
  — только один набор. `node tests/run.js --fingerprint` печатает отпечаток
  поведения, `node tests/check_fingerprint.js <факт.json>` сверяет его
  с `tests/baseline.json` (обновляйте эталон только вместе с намеренным
  изменением поведения). В `total`, кроме поведения, входит состав стилей —
  длина и хэш текста `css/style.css`; оформление таблицы стилей меняет `total`,
  не затрагивая ни одной секции.
- `builder/run.py` (двойной клик или `python3 builder/run.py`; нужны Python 3
  и Node.js LTS — npm и интернет не нужны) собирает в папке `builder/` файл `NADZIRATEL vX.Y.Z.W (release).html` — один файл в одну строку,
  без пробелов, комментариев и осмысленных имён, — и сам сверяет отпечаток
  поведения сборки с отпечатком исходников. Успех печатает `OK`; при провале
  рядом с HTML появляется `*.build.log` с подробностями.

## Оформление кода

- Комментарии — на русском, только там, где место действительно сложное:
  почему сделано так, а не иначе. Сборщик вырезает из релиза и комментарии JS,
  и комментарии внутри WGSL-шаблонов (включая вложенные фрагменты), поэтому
  на размер релизного файла они не влияют.
- Форматирование — [Prettier](https://prettier.io) с настройками из
  `.prettierrc.json`: `npx prettier --write .` приводит в порядок весь код
  проекта, кроме `builder/vendor/` (чужие библиотеки) и релизного HTML
  (он минифицирован намеренно) — они перечислены в `.prettierignore`.
  `builder/run.py` форматируется по тем же правилам: Python-часть — 4 пробела
  и строки не длиннее 100 знаков, встроенный JS-сборщик — тем же Prettier.
- Пробелы в разметке имеют значение: `.prettierrc.json` держит
  `htmlWhitespaceSensitivity: css`, чтобы форматирование не добавило пробелов
  вокруг строчных элементов, и `embeddedLanguageFormatting: off`, чтобы
  содержимое `style="…"` и WGSL-шаблонов не переформатировалось.

## Технические детали

- **Детерминизм.** Сид — любой текст (слово, фраза, эмодзи): через SHA3-512 он
  превращается в 512-битное состояние Xoshiro512**. У каждой подсистемы
  (лабиринт, лампы, монстр, текстуры, звук) свой параллельный поток (`jump()`),
  поэтому один и тот же сид даёт идентичный забег. Полный сид виден в паузе и
  копируется одним кликом.
- **Графика.** Рендер всегда через WebGPU; тяжёлые кадровые стадии (угловая
  карта теней, скиннинг, поле облучённости) выполняются в compute-шейдерах.
  Пресет графики меняет разрешение рендера/атласа и число сэмплов пост-эффектов,
  но не густоту темноты и не число источников света — переключение пресета не
  даёт игрового преимущества.
- **Масштаб мира.** 1 клетка ≈ 2.94 м, рост героя ровно 1.80 м. Скорости заданы
  в км/ч; походка Надзирателя выведена из походки игрока по равному числу
  Фруда (опорная нога не проскальзывает).
- **Режим разработчика** включается параметром URL `?dev=<пароль>` и нигде не
  сохраняется: в коде лежит только SHA3-512-дайджест пароля, а не сам пароль
  (ибо нефиг простым смертным читерить тут. Проходите игру честно!).
